# Product Specs

제품이 누구를 위해 어떤 동작과 정책을 제공해야 하는지 기록한다. 저장 구조, 라이브러리 선택과 구현 순서는 기능 설계나 실행 계획에 둔다.

## 사용

[템플릿](template.md)을 `<domain>.md`로 복사한다. 하나의 제품 영역을 한 문서에서 시작하고 충분히 커질 때 나눈다. 실제 생성한 문서만 아래 목록에 연결하고 프로젝트의 문서 지도에도 이 index를 등록한다.

정책에는 필요한 경우 `DOMAIN-RULE-001`처럼 안정적인 ID를 부여해 설계와 테스트에서 참조한다. 질문은 Open, Resolved, Deferred로 구분하고 답변 또는 다시 볼 조건을 남긴다. 작은 기능에 불필요한 ID와 문서를 강제하지 않는다.
