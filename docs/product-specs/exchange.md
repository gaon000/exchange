# exchange 제품 명세

상태: Draft

## 목적과 사용자

- 확인된 목표: 거래소를 구축한다.
- 근거: 2026-10-28 사용자가 프로젝트 목적을 “거래소를 만들고싶어.”라고 설명했다.
- 주요 사용자: 미확정. 아래 미결 질문의 답변을 바탕으로 구체화한다.

이 초안은 확인된 목표와 질문을 기록한다. 특정 거래 대상, 운영 방식이나 기능을 확정된 요구사항으로 취급하지 않는다.

## 사용자 행동

미확정: 사용자가 누구이며 어떤 거래 경험을 제공하려는지 아직 정해지지 않았다. 첫 버전의 사용자와 대표 흐름을 확인한 후 관찰 가능한 결과로 작성한다.

## 제품 정책과 예외

미확정: 거래 대상·서비스 방식·첫 버전 범위에 대한 합의가 없다. 이 항목이 정해지면 실제 필요한 정책과 실패·예외 시 사용자 경험을 구체화한다.

## 범위 밖

제품의 제외 범위는 미확정이다. 현재 문서 적용 작업의 범위는 협업 문서 구성까지이며 애플리케이션 구현과 운영 환경 구성은 별도 작업이다.
