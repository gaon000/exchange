## Purpose / Big Picture

사용자가 요청한 순서대로 최근 6개 커밋을 master에 반영하고 실제 CI를 확인한다. 기존 snapshot 1,000/s 실패 구간의 요청·snapshot 단계·WAL·GC·호스트 시각을 대조한 뒤, 정수 JSON 최적화를 포함한 현재 생산 버전의 정상 조건 처리량 경계를 같은 P6 기준으로 측정한다. 실제 전원 장애는 계속 보류한다.

## Surprises & Discoveries

이전 기준은 정상 10,000/s 3/3 통과, snapshot 1,000/s 2/3 통과다. snapshot1의 전체 요청 p99는 10.799209ms지만 마지막 5초 구간 p99는 39.254708ms다. 유효한 전체 p99만으로 창별 통과를 추정하지 않는다.

## Decision Log

- 2026-11-09: 새 5,000/s는 2/3, 2,000/s는 3/3, 3,000/s는 2/3 통과했다. 사전 정한 1,000/s 해상도의 최고 관찰 채택점/인접 실패점을 확인해 탐색을 종료한다. 병행 브라우저 작업과 높은 실행 중 호스트 부하 때문에 내재/전역 최대 용량이나 기존 결과 대비 회귀로 일반화하지 않는다.

- 2026-11-09: 명시적 재개 요청을 받아 보류를 해제했다. 이전 중단/실패는 덮어쓰거나 반복에서 제외하지 않는다. 저장된 build 7b9e720을 그대로 사용하고 모든 추가 출력은 새 경로에 기록한다. 여러 날짜의 호스트 상태가 같다고 가정하지 않는다.

- 2026-11-09: 사용자 요청으로 정상 처리량 측정을 보류한다. CPU 작업 축소 의향만으로 재개하지 않으며, 공간 확보와 명시적인 재개 요청 전에는 추가 부하를 실행하지 않는다. 계획은 미완료 Blocked로 유지한다.

- 2026-11-07: master d2d70ce의 생산 코드와 동일한 clean 빌드를 새로 고정한다. 성능 실행 중 로컬 빌드/테스트/재분석을 겹치지 않는다.
- 2026-11-07: 정상 탐색은 20,000/s부터 시작한다. 통과하면 두 배(최대 80,000/s), 실패하면 이전 통과점과 실패점의 1,000/s 단위 중간값을 확인한다. 최초 20,000/s 실패 시 10,000/s로 내려가며, 이 또한 실패하면 5,000→2,000→1,000/s 순서로 하한을 찾는다. 하한 미확보 또는 80,000/s 통과는 경계 미확정으로 명시한다. 단조 용량을 증명하지 않으며 관찰된 최고 채택점과 바로 위 실패점만 보고한다.
- 2026-11-07: 각 탐색 rate는 같은 새 빌드로 항상 독립 3회 전체를 실행한다. warmup 5초/측정 20초·20ms/5초 창·기존 criteria-v1·누락/운영 오류 0·runtime·계측·cooldown·유휴/전원/예산을 유지한다. 3회 중 실패가 있으면 해당 rate 미채택이며 실패 반복을 교체하지 않는다. 유휴 gate만의 중단은 기존 prefix 보존 재개를 사용한다.
- 2026-11-07: 500ms 누적 계측은 개별 호출 시각과 그 구간의 정확한 최대를 복원하지 못한다. UTC 상관·누적 count/sum 차이와 새 누적 최대, 실제 snapshot 사건 범위를 구분한다. 시각 겹침으로 단일 원인이나 커널 I/O 원인을 확정하지 않는다.

## Outcomes & Retrospective

master d2d70ce 머지/push/CI와 기존 snapshot 3회 재검증·응답 tail/저장/GC/호스트 대조를 완료했다. 정상 20,000/s는 2/3 통과로 미채택이고 10,000/s는 2회 완료 뒤 세 번째 실행 중 디스크 기준 때문에 중단됐다. 세 번째 실행은 raw 측정 유효성 true지만 봉인이 없고 WINDOW_2_P99도 실패한다. 당시 새 탐색은 하한이 미확정이었다. 사용자 재개 요청 뒤 같은 빌드의 새 9회를 수행해 2,000/s 3/3 통과·3,000/s 2/3 통과를 확인했다. 고유 신규 승인 주문은 1,297.90~1,297.95/s, 전체 요청 p99 최대 10.736750ms·최악 5초 창 15.625916ms였다. 이전 실패/불완전 실행을 포함한 15개 전체 판정을 보존했다. 이 호스트 조건의 관찰 경계이며 서버의 내재 최대 용량은 미확정이다. [결과·차단 보고서](../../benchmarks/snapshot-window-capacity.md)에 모든 실패·원본 hash·재개 조건을 기록했다.
