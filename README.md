# exchange

거래소를 구축하기 위한 프로젝트다. 현재는 AI와 사람이 함께 요구사항과 개발 작업을 정리할 문서 체계를 갖춘 단계이며, 애플리케이션은 아직 구현하지 않았다.

거래 대상, 주요 사용자, 실제 거래 또는 모의 거래 여부, 첫 버전 범위와 기술 스택은 미확정이다. 확인된 목표와 미결 질문은 [제품 명세 초안](docs/product-specs/exchange.md)에서 관리한다.

- [작업 안내](AGENTS.md): 개발 작업의 진입점과 공통 원칙.
- [문서 지도](docs/index.md): 문서별 책임과 템플릿 적용 이력.
- [구조](ARCHITECTURE.md): 현재 파일 구조와 아직 정하지 않은 시스템 경계.
- [개발 기준](docs/development.md): 개발 규칙과 실행 환경의 구성 상태.

실행·테스트·빌드 명령과 CI는 아직 미구성이다. 문서 적용과 애플리케이션 구현·실행 검증의 상태를 구분한다.
